# NetForge

**NetForge** is an industry-grade data processing tool designed with a clean, professional interface and advanced functionality. It features a unique stealth mode that disguises the application as a standard calculator to ensure discreet usage in professional environments.

## Features

- **Stealth Mode** The application launches as a fully functional calculator, keeping the main interface hidden until authorized.

- **Secure Access** Access involves a two-step authentication process:
  1. Enter the secret code `1971-2024` into the calculator and press `=`.
  2. To complete the authentication process and unlock the full suite of tools, please send an email to **[toha.240113@s.pust.ac.bd](mailto:toha.240113@s.pust.ac.bd)**.

- **Comprehensive Toolset** A wide range of utilities for data manipulation:
  - **Data Format**: Base64, Hex, Binary, and Decimal converters.
  - **Encryption/Encoding**: ROT13, URL Encode/Decode, HTML Entity, and XOR.
  - **Hashing**: MD5, SHA1, SHA256, and SHA512 generators.
  - **Code Tidy**: JSON and XML Beautify & Minify tools.
  - **Networking**: IP Defang and Refang utilities.
  - **Utils**: Various string manipulation and analysis tools.

- **Recipe System** Chain multiple operations together to process data in complex, automated workflows.

- **Modern UI** Features a polished, professional aesthetic designed for clarity, usability, and extended workflow sessions.

## Tech Stack

- **Frontend Framework**: [React](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: Vanilla CSS with modern features (Variables, Flexbox/Grid)
- **Crypto Library**: [Crypto-JS](https://github.com/brix/crypto-js)
- **Icons**: [Lucide React](https://lucide.dev/)

## Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/tijulkabir/netforge.git
   cd netforge
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

## Usage

1. **Start the development server**:
   ```bash
   npm run dev
   ```

2. **Open the application**:

3. **Unlock NetForge**:

To create a production build:
